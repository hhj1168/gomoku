🧪 测试建议

桌面浏览器：

  1. 按 F12 打开开发者工具
  2. 点击设备工具栏图标（或按 Ctrl+Shift+M）
  3. 选择不同的设备预设进行测试
  4. 尝试调整窗口大小观察响应式变化

移动设备：

  1. 直接在手机或平板浏览器中打开
  2. 尝试横竖屏切换
  3. 测试触摸操作的流畅性
  4. 添加到主屏幕以获得类似原生应用的体验

📊 支持的屏幕尺寸

  • 小手机： < 400px 宽
  • 标准手机： 400px - 600px 宽
  • 大手机/小平板： 600px - 768px 宽
  • 平板： 768px - 1024px 宽
  • 笔记本： 1024px - 1400px 宽
  • 台式机： 1400px - 1920px 宽
  • 超宽屏/电视： > 1920px 宽
