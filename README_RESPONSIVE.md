# 五子棋游戏 - 响应式优化说明

## 🎯 优化概述

本次优化使五子棋游戏能够完美适配**手机、平板、电脑、电视**等多种设备，提供一致且优秀的用户体验。

## 📱 支持的设备类型

### 1. **移动手机** (Portrait & Landscape)
- 小屏手机 (< 400px)
- 标准手机 (400px - 600px)
- 大屏手机 (600px - 768px)

### 2. **平板设备**
- 小平板 (768px - 900px)
- 标准平板 (900px - 1024px)
- 横屏和竖屏模式均优化

### 3. **电脑屏幕**
- 笔记本 (1024px - 1400px)
- 台式机 (1400px - 1920px)

### 4. **大屏设备**
- 超宽屏 (1920px+)
- 电视屏幕
- 4K/8K 显示器

## 🎨 主要优化特性

### 1. **动态尺寸系统**
使用 CSS 变量和 `clamp()` 函数实现流畅的尺寸缩放：

```css
--scene-size: min(90vw, 90vh, 600px);
--board-size: calc(var(--scene-size) * 0.9);
--font-size-h1: clamp(1.5rem, 4vw, 2.5rem);
```

### 2. **响应式布局**
- **桌面**: 横向布局 (控制面板 + 棋盘)
- **平板竖屏**: 纵向布局 (控制面板在上，棋盘在下)
- **手机**: 优化的纵向布局，最大化屏幕利用率

### 3. **触摸优化**
- 禁用文本选择和长按菜单
- 优化按钮点击区域
- 触摸设备的视觉反馈
- 防止双击缩放

### 4. **横竖屏适配**
- 自动检测屏幕方向
- 针对横屏模式的特殊优化
- 超矮屏幕 (< 500px 高度) 的紧凑布局

### 5. **高DPI屏幕支持**
- Retina 显示屏优化
- 更清晰的棋子阴影效果
- 适配高像素密度设备

## 🔧 技术实现

### CSS 变量系统
```css
:root {
    /* 响应式尺寸变量 */
    --scene-size: min(90vw, 90vh, 600px);
    --board-size: calc(var(--scene-size) * 0.9);
    --panel-width: min(280px, 90vw);
    --gap-size: clamp(20px, 3vw, 50px);
    --padding-base: clamp(15px, 2vw, 30px);
    
    /* 字体大小 */
    --font-size-h1: clamp(1.5rem, 4vw, 2.5rem);
    --font-size-h3: clamp(0.9rem, 2vw, 1.1rem);
    --font-size-btn: clamp(0.9rem, 2vw, 1.1rem);
}
```

### 媒体查询策略
- 使用 `orientation` 检测横竖屏
- 结合 `max-width` 和 `max-height` 精确控制
- 针对特殊场景的专门优化

### 移动设备Meta标签
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="theme-color" content="#2c3e50">
```

## 🌟 特殊优化

### 1. **动态视口高度**
使用 `100dvh` 替代 `100vh`，解决移动浏览器地址栏的问题。

### 2. **触摸反馈**
```css
@media (hover: none) {
    .cell:active::after {
        /* 触摸设备的视觉反馈 */
    }
}
```

### 3. **无障碍支持**
```css
@media (prefers-reduced-motion: reduce) {
    /* 为运动敏感用户减少动画 */
}
```

### 4. **比例保持**
所有棋盘元素使用百分比计算，确保在任何尺寸下保持正确比例：
```css
.piece {
    width: calc(var(--board-size) * 0.052);
    height: calc(var(--board-size) * 0.052);
}
```
